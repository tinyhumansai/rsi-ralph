# Plan: the `tinyrsi` CLI

Implements [`../specs/rsi-cli.md`](../specs/rsi-cli.md). Each step is one pull
request, green on the four contract commands.

1. **Spec and plan.** This file and the spec.
2. **`tinyrsi-cli` skeleton.** `manifest/` (parse and validate over a path to
   text map, every error variant tested, serde pinned), `keys/`, and
   `tinyrsi check`. The hive package is validated through `tinyhivemind_lang`.
3. **Sign test.** An exact one-sided sign test beside `decide` in
   `crates/tinyrsi-score/src/scoring/`.
4. **Engine on a `dir` subject.** `subject/`, `gate/`, `score/`, `brief/`,
   `store/`, `engine/`; `run`, `score`, `runs`, `show`. The hive proposer is a
   trait so tests can drive the engine with a scripted proposer.
5. **`git` subject.** Worktrees, auto-commit, surface checks, fast-forward
   promotion, the incumbent cache.
6. **`tinyrsi-gateway`.** Port of oh-bench-rsi's spend-capped proxy, started
   in-process; `budget` and `keys.openrouter`.
7. **`tinyrsi-swarm`.** The hive proposer on OpenHuman agents; model,
   temperature and tool-key resolution.
8. **Creativity.** The tinybackrooms retreat before the hive, `{{ideas}}`, and
   retreat memory in the store.
9. **`serve`.** Static rsi-viz export embedded behind the `ui` feature, API
   routes in Rust over the store, served by default during `run`.
10. **Example loops.** `loops/graph-coloring` (and `math-problem`) run offline
    end to end through the binary in an integration test.
11. **oh-bench-rsi migration.** `loops/lme2-recall/` in that repository;
    delete its loop driver, swarm host, campaign crate and gateway.

In progress.
